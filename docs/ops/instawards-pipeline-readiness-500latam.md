## 1. Framing — UNBLCK closes the 0→1 gap

Instawards funds a **focused 30-day, testnet-demoable sprint** (Initial track ≈ $5k). SDF expects Ecosystem Partners to:

1. Identify builders worth backing (first-hand confidence, not grant-seekers who appeared from nowhere).
2. Shepherd them weekly through the sprint.
3. Close out cleanly with evidence.

**UNBLCK’s role in this pipeline is deliberate:**

| Gap | Who owns it |
|-----|-------------|
| **0 → 1** — problem clarity, Stellar fit, SOW quality, Stellar Raven consult, weekly cadence, demo discipline, closeout evidence | **UNBLCK Cohort + sprint ops** over the coming months |
| **Sprint build** — ship a scoped Stellar deliverable in ~30 days once funded | **Builder**, shepherded by UNBLCK |
| **Vetting / KYC / payout / Raven** | **SDF / Instawards** (UNBLCK relays and unblocks) |

Builders recommended here are **not** expected to already be “Instawards-ready” on every dimension. They enter as **pipeline candidates**. UNBLCK runs them through Cohort curriculum and sprint shepherding **in parallel with (or immediately preceding) the Instawards 30-day clock**, so missing 0→1 pieces get closed by the program — not left as silent risk.

**Pipeline path (this report):**

```
500 LatAm / hackathon signal
        ↓
UNBLCK Fast-track / Cohort admission (ops)
        ↓
Pipeline readiness rubric (below) → GO / CONDITIONAL / HOLD
        ↓
SOW + Raven + Airtable (UNBLCK as Ecosystem Partner)
        ↓
KYC → test tx → 30-day sprint (weekly UNBLCK check-ins)
        ↓
Closeout evidence → possible Follow-on / Build Award later
```

Event invite/code for the public Insta Awards form remains required where that gate applies; this report is the **ops endorsement track**, not a bypass of program rules.

## 2. Pipeline readiness rubric

Score each criterion **0 / 1 / 2**. Use the decision rule at the bottom. Rubric maps directly to Operator Guide Do’s/Don’ts, archetypes, and Fresh (Initial) submission expectations.

### Scoring key

| Score | Meaning |
|-------|---------|
| **2** | Clear evidence today |
| **1** | Partial / plausible; UNBLCK can close in Cohort + pre-sprint weeks |
| **0** | Missing or disqualifying; do not submit until fixed |

### Rubric dimensions

| # | Dimension | What “2” looks like (Guide-aligned) | What UNBLCK covers if “1” |
|---|-----------|--------------------------------------|---------------------------|
| **A** | **Builder confidence** | First-hand relationship; not cold inbound; not purely grant-seeking | Warm intros, hub presence, mentor calls, trust over weeks |
| **B** | **Archetype fit** | Fintech→Web3, Web3 MVP on Stellar, or highly investable but too early for equity | Reframe pitch to Stellar sprint; Raven for ecosystem overlap |
| **C** | **Stellar commitment (sprint)** | Willing to build **this sprint on Stellar** (need not be Stellar-native yet) | Curriculum week 1 + technical mentor / Discord routing |
| **D** | **30-day scope** | Deliverable can demo on **testnet** in ~30 days; uses Stellar building blocks | Scope cut with Ops; SOW worksheet; Raven before finalize |
| **E** | **Stellar touch (not generic Web2)** | Deliverables clearly touch Stellar / on-chain UX | Rescope Web2 lines out; bridge framing only where real |
| **F** | **Technical footprint** | GitHub (or collaborator access); build path exists | Repo hygiene, Scaffold Stellar, testnet deploy plan |
| **G** | **Cadence & communication** | Can do weekly check-ins; known contact path | UNBLCK weekly shepherding; escalate silence early |
| **H** | **SOW / budget hygiene** | Budget = technical + design hours for deliverables; no legal/incorp/pure marketing | SOW template workshop; custdev interviews OK, ads not |
| **I** | **Closeout path** | Clear technical or Loom/demo evidence possible | Demo Day practice; evidence checklist before day 30 |

### Decision rule (pipeline entry)

| Total (max 18) | Decision | Meaning |
|----------------|----------|---------|
| **14–18** | **GO — submit path** | Ready for SOW polish → Raven → Airtable with light UNBLCK support |
| **9–13** | **CONDITIONAL — program path** | Enter Cohort / pre-sprint; UNBLCK closes 0→1; submit when ≥14 or Ops overrides with written risks |
| **0–8** | **HOLD** | Do not endorse; nurture or decline |

**Hard stops (any one → HOLD until fixed), per Guide:**

- Feels like unknown grant-seeker with no relationship  
- Scope cannot produce a real testnet demo in 30 days  
- Pure Web2 / no Stellar touch after rescope  
- Unwilling to do weekly contact  
- Budget dominated by ineligible spend (legal, incorporation, institutional marketing)

**Fresh vs Follow-on:** This report is for **Fresh / Initial (testnet MVP)** only. Follow-on requires custdev traction evidence — out of scope here.

## 3. How recommended builders move with the sprint

For CONDITIONAL and GO candidates from 500 LatAm:

1. **Admit** via Fast-track / next Cohort (ops mark in CRM + admissions).  
2. **Score** with this rubric; store scores + notes on the Exponential contact.  
3. **Pre-sprint (UNBLCK 0→1):** problem/Stellar fit, SOW draft, Raven consult, GitHub, weekly habit.  
4. **Submit** when A–I are 1–2 with no hard stops.  
5. **During funded sprint:** same weekly UNBLCK check-ins as Cohort sprint ops; route tech to Developer Discord.  
6. **Closeout:** UNBLCK closes on builder’s behalf with evidence within 10 business days of window end.

They **go through the program as they go through the sprint** — Cohort content and Instawards shepherding are one operating system, not two separate funnels.
